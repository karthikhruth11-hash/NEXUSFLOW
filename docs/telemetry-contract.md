# NexusFlow Telemetry Ingestion Contract & Time Semantics

## 1. Payload Schema

Telemetry payloads can be ingested as a single JSON object or as a batch.

### Single Telemetry Reading
```json
{
  "deviceId": "turbine-generator-01",
  "timestamp": "2026-10-09T14:30:00.000Z",
  "measurements": {
    "temperature": { "value": 78.4, "unit": "celsius" },
    "vibration": { "value": 2.1, "unit": "mm/s" },
    "rpm": { "value": 3000, "unit": "rpm" }
  },
  "eventId": "evt-tg01-92817412",
  "sequence": 1042,
  "meta": {
    "firmware": "v2.4.1",
    "location": "plant-alpha-bay-3"
  }
}
```

### Batch Ingestion (`POST /api/telemetry`)
```json
{
  "readings": [
    { /* reading 1 */ },
    { /* reading 2 */ }
  ]
}
```

---

## 2. Field Specifications and Validations

| Field | Type | Constraints | Semantics |
|---|---|---|---|
| `deviceId` | `string` | 1-128 chars, non-empty, ASCII alphanumeric and hyphens/underscores | Identifier of physical sensor/PLC. Must match authenticated device key. |
| `timestamp` | `string` | Valid ISO-8601 UTC timestamp (e.g., `2026-10-09T14:30:00.000Z`) | **Event time** at measurement origin. |
| `measurements` | `object` | Record of 1-64 keys. Key: 1-64 chars. | Map of sensor metric names to values. |
| `measurements[k].value` | `number` | Finite IEEE 754 float | Numeric metric value. |
| `measurements[k].unit` | `string` (opt) | Max 32 chars | Engineering unit (e.g., `celsius`, `psi`, `v`, `hz`). |
| `eventId` | `string` (opt) | Max 128 chars | Idempotency key from device. Duplicate eventIds within deduplication window are dropped idempotently. |
| `sequence` | `number` (opt) | Non-negative integer | Monotonic sequence number for packet loss tracking. |
| `meta` | `object` (opt) | Arbitrary key-value JSON | Metadata (firmware, location, hardware model). |

## 3. Time Semantics

### Event Time vs Ingest Time
- **Event Time (`timestamp`):** Generated by the device clock at sampling time. Used for windowing aggregations (e.g., sliding 5-reading or 10-second averages), rate-of-change, and for-duration timers.
- **Ingest Time (`ingestTimestamp`):** Attached automatically by the NexusFlow API server upon receipt. Used for auditing, ingestion SLA monitoring, and calculating end-to-end processing latency:
  $$\text{latency}_{\text{ingest-to-alert}} = t_{\text{alert\_created}} - t_{\text{ingest}}$$

### Clock Skew Tolerance
- **Future timestamps:** Any reading with `timestamp > (now + 10s)` is rejected with HTTP `400 Bad Request` (`CODE: CLOCK_SKEW_FUTURE`).

### Lateness Boundary (`MAX_LATENESS_SECONDS`, default: 60s)
- **Late Readings:** Any reading with `timestamp < (now - MAX_LATENESS_SECONDS)` is:
  1. Durably persisted to MongoDB with `{ late: true }`.
  2. Flagged and **excluded from live sliding windows** to prevent retroactive corruption of moving averages and alert state machines.

### Duplicate Readings (`eventId`)
- If an `eventId` has already been ingested within the deduplication cache window, the API returns HTTP `202/201` idempotently, increments the `telemetry_duplicate_dropped_total` metric, and avoids duplicate window processing.

## 4. HTTP Ingestion Semantics

- **Default (`POST /api/telemetry`):** Returns HTTP `202 Accepted` with:
  ```json
  {
    "success": true,
    "data": {
      "accepted": 1,
      "rejected": 0,
      "ingestTimestamp": "2026-10-09T14:30:00.045Z"
    }
  }
  ```
  *Meaning:* Payload validated, queued to the in-memory `TelemetryBus` for real-time engine processing, and queued for MongoDB Time Series persistence.

- **Synchronous Durable Confirmation (`POST /api/telemetry?durable=true`):** Returns HTTP `201 Created`.
  *Meaning:* Payload validated, written and acknowledged by MongoDB Time Series storage before response.

---

## 5. Device Authentication

Ingesting devices must authenticate via HTTP header:
```http
x-device-api-key: devkey_<random_token>
```
The server checks the cryptographic hash of the key against authorized devices. A device key is scoped strictly to its `tenantId` and `deviceId`. A device cannot submit telemetry under a different `deviceId`.
